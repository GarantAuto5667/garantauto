# Сайт автосервиса «ГарантАвто»

Сайт-визитка для автосервиса «ГарантАвто» (Москва, Люблинская ул., 1) с
**панелью управления**, через которую клиент сам меняет тексты, цены и фото.
Вся исходная информация взята с Яндекс-карточки — см.
[`materials/yandex-card-data.md`](materials/yandex-card-data.md).

Источник данных: https://yandex.ru/maps/org/garantavto/1066992215/

## Структура проекта

```
ГарантАвто/
├── index.html          # Главная страница сайта
├── admin.html          # ПАНЕЛЬ УПРАВЛЕНИЯ для клиента
├── content.json        # Контент сайта (тексты, цены, фото). Меняется через админку
├── privacy.html        # Политика конфиденциальности (152-ФЗ)
├── security.html       # Политика безопасности
├── .htaccess           # Заголовки безопасности + HTTPS (для Apache)
├── robots.txt          # Правила для поисковых роботов
├── css/style.css       # Стили
├── js/
│   ├── content.js      # Контент по умолчанию (запасной вариант)
│   ├── main.js         # Логика сайта: загрузка content.json и отрисовка
│   └── admin.js        # Логика панели управления
├── assets/             # Фотографии (hero, about, g1..g6)
└── materials/          # Исходные материалы с Яндекс-карточки
```

## Как посмотреть локально

Сайту нужен локальный сервер (из-за загрузки `content.json`):

```bash
cd /Users/mac/Desktop/ГарантАвто
python3 -m http.server 8000
```

- Сайт: http://localhost:8000
- Панель управления: http://localhost:8000/admin.html

## Панель управления (для клиента) — admin.html

Клиент меняет сайт **сам, без программиста**:

1. Открывает `admin.html`.
2. Меняет тексты, цены, фотографии в понятных полях (сохраняется автоматически
   в его браузере).
3. Кнопка **«Предпросмотр»** — открывает сайт с внесёнными изменениями
   (`index.html?preview=1`, читает черновик).
4. Кнопка **«Опубликовать»** — скачивает файл `content.json`.
5. Клиент загружает `content.json` в папку сайта на хостинге (заменяя старый) —
   и изменения видят все посетители.

**Фотографии** загружаются прямо в панели: они автоматически уменьшаются,
сжимаются и сохраняются внутри `content.json` (в формате data-URL). Отдельно
загружать картинки на хостинг не нужно — публикуется один файл `content.json`.

Кнопка **«Загрузить файл»** — импорт ранее скачанного `content.json` (например,
чтобы продолжить редактирование на другом компьютере).
Кнопка **«Сбросить к исходному»** — вернуть контент по умолчанию.

> Как это работает: посетители сайта видят опубликованный `content.json`.
> Если его нет — сайт показывает значения из `js/content.js` (не сломается).

### Защита панели управления
Файл `admin.html` доступен по прямой ссылке. Перед публикацией рекомендуется
закрыть его паролем на уровне хостинга (Basic Auth). Пример для Apache — создать
`.htpasswd` и добавить в `.htaccess`:

```apache
<Files "admin.html">
  AuthType Basic
  AuthName "Панель управления"
  AuthUserFile /полный/путь/.htpasswd
  Require valid-user
</Files>
```

## Фотографии и логотип

- **Логотип** (`assets/logo.jpg`) — фирменный знак клиента, взят с их Яндекс-карточки
  (используется в шапке, подвале и как favicon на всех страницах).
- **Фото цеха «Сход-развал 3D»** (`assets/g7.jpg`) — реальное фото их сервиса с
  Яндекс-карточки.
- Остальные фото в `assets/` (hero, about, g1–g6) — бесплатные стоковые изображения
  с Pexels (лицензия Pexels: свободное коммерческое использование, без обязательной
  атрибуции).

Клиент может заменить любое фото своим через панель управления. На карточке есть
и другие реальные фото сервиса — при желании их можно добавить через админку.

## Форма заявки — важно

Сайт **статический**, без бэкенда. Форма заявки сейчас **не отправляет данные**:
после отправки показывается подтверждение, а данные очищаются (намеренно, чтобы
не передавать персональные данные небезопасно).

Чтобы принимать заявки, подключите обработчик в `js/main.js`
(блок «здесь должна быть отправка на ваш сервер»): свой серверный скрипт по
HTTPS, сторонний сервис форм с CAPTCHA или интеграцию с CRM/мессенджером.

## Безопасность

Реализовано на уровне статики:
- **CSP** (Content-Security-Policy) на всех страницах;
- **Referrer-Policy** `strict-origin-when-cross-origin`;
- внешние ссылки с `rel="noopener noreferrer"`;
- нет сторонних трекеров и рекламных скриптов;
- валидация и ограничение длины полей формы;
- согласие на обработку ПДн со ссылкой на политику конфиденциальности;
- `admin.html` закрыт от индексации (`noindex`).

На сервере включите заголовки из `.htaccess` (HSTS, X-Content-Type-Options,
X-Frame-Options, Permissions-Policy) и принудительный HTTPS. Для Nginx:

```nginx
add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
add_header X-Content-Type-Options "nosniff" always;
add_header X-Frame-Options "SAMEORIGIN" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
add_header Permissions-Policy "camera=(), microphone=(), geolocation=()" always;
```

## Что заменить перед публикацией

- **Домен:** укажите реальный домен в `robots.txt` (Sitemap) и мета-тегах Open Graph.
- **Точный график по дням:** на карточке отображается «Открыто до 20:00».
  Уточните режим по дням недели и поправьте в панели управления.
- **Реквизиты организации** (ИП/ООО, ИНН) — добавьте в подвал/политику при необходимости.
- **Пароль на `admin.html`** (см. раздел выше).
